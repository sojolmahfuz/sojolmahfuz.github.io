# Al Amin Mahfuz — Futuristic Personal Website & Admin Command Deck (`NEURAL.OS // 2026`)

Futuristic, animation-rich personal portfolio website and live **NEURAL.CMS Admin Command Deck** for **Al Amin Mahfuz** (*Senior Lecturer in CSE @ Rajshahi Science and Technology University (RSTU), Natore | Full Stack Developer | AI Expert*).

- **Live Website:** https://sojolmahfuz.github.io
- **Admin Command Login:** https://sojolmahfuz.github.io/admin.html

## Quick Start (Local Development)

1. **Local Live + Persistent CMS Server:**
   ```bash
   node server.mjs
   ```
   - **Public Portfolio:** http://localhost:4173
   - **Admin Command Deck:** http://localhost:4173/admin.html
2. **Instant Offline Open:** Open `index.html` or `admin.html` directly in any browser (`localStorage` + `BroadcastChannel` keep tabs synced).

- `index.html` — Public portfolio with SVG orbital HUD rings, interactive `MAHFUZ.AI` MCP console, 3D-tilt Bento grid, filterable skills matrix, scroll-driven laser timeline, featured projects showcase, client pods, and direct transmission uplink.
- `styles.css` — Deep-space cyber-glass & academic light-mode design system.
- `script.js` — 60fps 3D neural synapse `<canvas>`, cybernetic dual cursor, magnetic buttons, glyph scramble decoder, dynamic role typewriter, MCP AI console, and live CMS hydration.

- `cms-store.js` — Shared `NeuralCMS` store with salted SHA-256 authentication, `localStorage` + `/api/cms` persistence, and real-time `BroadcastChannel` sync.
- `server.mjs` — Zero-dependency Node.js static + `/api/cms` server.
- `assets/` — Portrait photo, institutional client logos (BCC, Bangladesh Hi-Tech Park Authority, SSL Wireless), and digital signature.
